**The mechanism, from the instrumented ugen's own free list.** Its `.text` was

GP scratch free list per procedure in the fixed order t6, t7, t8, t9, t0, t1,

takes the first nine entries of the list. The target draws nine and takes the

#### 2026-09-12, lane `p8-close`: the recorded p2 force sweep is FALSIFIED

The entry above states that "a full p2 force sweep (every web against every
colour and the split path, then a second greedy round) never beats 8", and
reads that as proof the residual sits below globalcolor. It does beat 8, on the
INCUMBENT body, by two: forcing the `bitCount` web to colour 7 scores **6** at
size delta 0, and so does forcing `nextCursor`'s web to colour 7. On the
advance-before-store body the same two forces score **0**.

The likely cause is a measurement trap worth stating plainly, because it makes
a dropped force indistinguishable from a legitimate decline: **`CDX_FORCE` is
silently ignored unless `CDX_PROC` also names the procedure ordinal**, and an
ignored force returns a byte-identical object, which is exactly what L101 says
an already-forbidden decline looks like. Run here as a deliberate control,
`CDX_FORCE=p2:w0=c7` without `CDX_PROC` returns the unforced object and no
record carries a `forced` value other than -2. Every force quoted in this shard
was run with `CDX_PROC=11` and checked on the record's `forced` field, and each
one comes back `decision=color reg=t0 forced=7`, with no `force_declined` line.

The consequence for the reading is large. The residual is NOT below
globalcolor; it is a globalcolor decision, and the decision is named. What sits
below globalcolor is only the free list that the decision drives.
