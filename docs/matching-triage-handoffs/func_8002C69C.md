#### 2026-09-12, lane `p8-close`: the ring phase is read out of ugen and priced to zero

Baseline reproduces: 112 bytes, 28 of 28 instructions, delta 0, frameless, 8
relocation-masked words, first mismatch +0x18. Aligner: 20 byte-exact, 8

**The mechanism, from the instrumented ugen's own free list.** Its `.text` was
confirmed byte-identical to the tree's object for this TU first. ugen builds a
GP scratch free list per procedure in the fixed order t6, t7, t8, t9, t0, t1,
t2, t3, t4, t5, hands entries out in that order without reuse, and REMOVES from
it every register globalcolor has coloured. Two other procedures in this file
remove t0, and t0 with t1, for exactly that reason, and in both the removed
register does appear in the object. This body draws nine scratch values and so
takes the first nine entries of the list. The target draws nine and takes the
same list with t0 missing.

**Two edits, and neither is worth anything alone.**

1. The bit advance must be written BEFORE the mask store. Scratch is handed out
   in source order, and the target's list is a plain one-position shift of ours
   everywhere except at the shifted mask, which sits two positions on because
   the advance already holds the entry between. Making that swap alone is a
   regression from 8 to 11.
2. The procedure needs one more globalcolor-coloured web at colour 7. Colour 7
   is t0 on this procedure, decoded by forcing the reset-constant web through
   colours 7 to 12 and reading the register the record names.

**The pair is worth exactly the whole residual.** On the advance-before-store
body, forcing either of this procedure's two INVISIBLE webs to colour 7 returns
an object at ZERO relocation-masked words and size delta 0. Those two are the
`bitCount` parameter's web and `nextCursor`'s; neither shows its colour in the
object, which is why moving it costs nothing. The forces are accepted, not
declined -- the record carries the forced decision and the re-decision of the
remainder. A full phase-two force sweep of all eight webs against colours 1 to
14 and the split path, on that body, puts only those two cells at zero; the
cursor web and the reset-constant web at colour 7 reach 3, and the
reset-constant web at the split path reaches 10.

**Why colour 7 is unreachable from source.** Phase two colours in ascending web
number and each web takes the lowest colour not forbidden, where forbidden
means an interfering web that is already assigned or whose register the ABI
pins. Two facts then close it. The `bitCount` web is decided FIRST, so nothing
but the pinned argument registers can forbid anything for it, and its own home
is never forbidden -- it can only ever take colour 5. And the 0x80 reset
constant is a type-2 constant web; in every source shape measured here,
constant webs are numbered above every type-3 symbol web, so the constant is
always the LAST decision and always takes the highest colour in use. The target
keeps it on a3, which is colour 6. So no web decided before it can have colour
6 forbidden, and colour 7 is out of reach for `nextCursor` as well.

Reopening this needs one of exactly two things: an invisible web numbered above
the constant table, or a second mechanism that removes a register from ugen's
scratch free list. Nothing else changes the number.

#### 2026-09-12, lane `p8-close`: the recorded p2 force sweep is FALSIFIED

The entry above states that "a full p2 force sweep (every web against every
colour and the split path, then a second greedy round) never beats 8", and
reads that as proof the residual sits below globalcolor. It does beat 8, on the
INCUMBENT body, by two: forcing the `bitCount` web to colour 7 scores **6** at
size delta 0, and so does forcing `nextCursor`'s web to colour 7. On the
advance-before-store body the same two forces score **0**.

The likely cause is a measurement trap worth stating plainly, because it makes
a dropped force indistinguishable from a legitimate decline: **`CDX_FORCE` is
silently ignored unless `CDX_PROC` also names the procedure ordinal**, and an
ignored force returns a byte-identical object, which is exactly what L101 says
an already-forbidden decline looks like. Run here as a deliberate control,
`CDX_FORCE=p2:w0=c7` without `CDX_PROC` returns the unforced object and no
record carries a `forced` value other than -2. Every force quoted in this shard
was run with `CDX_PROC=11` and checked on the record's `forced` field, and each
one comes back `decision=color reg=t0 forced=7`, with no `force_declined` line.

The consequence for the reading is large. The residual is NOT below
globalcolor; it is a globalcolor decision, and the decision is named. What sits
below globalcolor is only the free list that the decision drives.

#### The impossibility argument, stated completely

Phase two colours in ascending web number, each web taking the lowest colour
its forbidden mask leaves, where the mask carries every interfering web that is
already assigned plus every interferer whose register the ABI pins. Colour 7 is
`t0`. The target keeps the 0x80 reset constant on `a3`, which is colour 6, and
uses no `t0` at all, so some OTHER web must hold colour 7 and hold it
invisibly.

That web must be decided before the constant, because the constant is a
constant-table web and constant-table webs are numbered above every symbol web
in every source shape measured here. To reach colour 7 it needs colour 6
forbidden, so it must interfere with a web already coloured `a3`. The only
`a3` web is the constant, which is decided last. Two webs may share `a3` if
they do not interfere, so the loophole is a SECOND `a3` web decided earlier --
and that one must not interfere with the constant, whose range starts at the
constant materialisation in the preheader and covers the whole loop. So the
second `a3` web would have to live entirely before that point, in the first
four instructions of the preheader; but then it cannot interfere with an
in-loop colour-7 web either, and a colour-7 web that also lives only there
cannot have colour 2 forbidden, because the mask web is not live in the
preheader on either side. The loophole closes.

Measured against exactly that, all at delta 0 and none producing a colour-7
web: a declared reset local assigned in the preheader before and after the
initial shift, which uopt folds straight back into the constant web and costs a
word; a preheader mask pre-read; a preheader-only cursor alias; and a
preheader-only scalar derived from the parameters, in two positions. Every one
of them leaves the same eight webs on the same six colours.

So the reopen needs one of exactly two things, and nothing smaller: an
invisible web numbered ABOVE the constant table, or a second mechanism that
removes a register from ugen's scratch free list. The first would also want
checking against the possibility that this function was compiled in a different
translation unit, since the free-list order and the colour table are both per
procedure.
