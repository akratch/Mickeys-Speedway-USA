The allocation law behind that was measured on this translation unit with two
controlled experiments. With three hoisted loads and two hoisted literals the

in-loop read leaves two loads in the lowest two ascending and moves the
literals to the three highest descending. Making every value an in-loop read
gives the literals the highest four descending and spills the three global
addresses into saved integer registers instead, which costs four words. So the
group a value belongs to is fixed by whether it is a hoisted memory load or a
materialized literal, and each group's direction is fixed with it. The target's
assignment inverts both directions at once, which no partition of these five
values into the two groups can produce.
