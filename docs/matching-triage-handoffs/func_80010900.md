The pass adds one fact that changes what has to be searched. Merging the sum
into the length variable -- dropping the intermediate float entirely, so that
one symbol is assigned the sum and then reassigned the square root -- is
BYTE-IDENTICAL to the recorded two-variable form. So the sum is not the
symbol's first web at all: uopt's copy propagation removes the symbol's first
definition and the sum survives as an expression temporary, whose only two uses
are the comparison against zero and the call argument. Both sit before the
call, the temporary crosses nothing, and a caller-saved float register
therefore costs it zero, which is exactly the cost the instrumented records
report.

Measured and flat at three words, all zero size delta: the sum written

reversed so the intermediate takes the length's value; and the length variable
declared first. Removing the intermediate declaration entirely is 11 words,
because its frame cell is load-bearing.

The requirement is now stated against the temporary rather than the symbol: the
sum's expression web must be live across the square-root call, since that is
the only thing that prices the caller-saved float registers above the
callee-saved one. No source form found here does that without changing what the
function computes, and forcing the colour costs eight bytes because a fourth

Read off both objects rather than off the census, the three words are one value
in three positions: the sum's destination, the zero comparison's second operand,
and the copy into the argument register. The target writes the sum straight into
the callee-saved float register that the length variable already owns and that

call": the length variable's FIRST definition must survive uopt, and the web it
belongs to already crosses the call.

**L144 is refuted here, with a price.** The address form is not a cheaper
`volatile`: taking the length variable's address at the guard, at the call
argument, or at both costs twelve bytes and 93 words, because it moves the
variable to a memory home and every read becomes a load. The reload is the
wrong half of `volatile` for this residual, which wants no reload at all.

Also newly measured and byte-identical to the retained form at three words, all
zero size delta: the sum split into two statements with the second accumulating;
the same written as a compound assignment; a dead zero initialisation in front
of the sum; a self-assignment after it; the square root taken into the spare
float and copied back; and the guard read through the spare float while the call
argument keeps the length variable. uopt normalises all six to the same object,
which is the measured form of the recorded copy-propagation result: any
expression whose operands are unmodified between the definition and the uses is

The one axis that would reach it and was not available: a store between the
